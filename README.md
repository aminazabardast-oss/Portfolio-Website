# Portfolio-Website 
A personal portfolio website showcasing my skills, projects, and experience as an IT & Computer Networking student.  
This website will include sections such as **About Me**, **Skills**, **Projects**, and **Contact** to present my professional work.

## Technologies Used
- HTML5  
- CSS3  
- JavaScript  

## Installation
1. Click the green **Code** button at the top of this repository.
2. Select **Download ZIP** or clone the repository:
3. 3. Open the project folder.  
4. Open `index.html` in any web browser.

---

## Usage
- Open `index.html` to view the homepage.  
- Navigate to sections such as **Skills**, **Projects**, and **Contact**.  
- This portfolio will later be deployed using GitHub Pages or Netlify.

**Example:**  
- Open `index.html` → Check Skills section → Explore Projects.
